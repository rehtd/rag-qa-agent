# 数据说明

- 本数据集为演示用途，用于「香港金融消费者双语问答助手」作品集项目。
- 内容来源：香港官方消费者教育公开资料——IFEC 投资者及理财教育委员会（www.ifec.org.hk）与香港金融管理局「智醒消费者」（www.hkma.gov.hk/chi/smart-consumers/），以及少量演示自编条目（已在 source 字段标注）。
- 使用策略：官方内容只做「短引用（≤100 字）+ 改写摘要」，不逐字复制大段原文；每条附来源链接与收录日期。
- 页面快照存放于 `data_snapshots/`（不入 git）。
- 使用前请核对来源网站的使用条款；本项目仅为教育演示，不构成投资建议。
